04 / Layout and interaction

Responsive by default.

  • Grid and spacing

    Maximum page width: 1180px. Gutters: 28px, reducing to 20px on phones. Cards: three columns, then two below 960px, then one below 650px. Radius: 20px for cards, 10px for buttons.

  • Navigation

    Sticky, translucent navigation. Mobile Menu button exposes its expanded state and closes with Escape, an outside click, or a selected link. Without JavaScript, navigation links stay visible.

  • Theme

    Follow the device preference initially. A user choice persists in local storage and is applied before the first paint. Storage failures do not stop the control.

  • Motion

    Typing runs once for about two seconds; assistive technology gets a static equivalent. Reduced-motion mode disables typing, animation, smooth scrolling, and transitions.

  • Accessible states

    Keyboard focus has a visible outline. Controls have a minimum 44px height. Images have descriptive alternatives. Skip navigation leads directly to main content.
