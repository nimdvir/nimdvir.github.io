# Original Hebrew articles for the interview images

The archive contains **25 Hebrew articles**. It includes 19 existing Hebrew captures from the website archive, five new publisher captures, and the original four-page La’Isha PDF for Anjelica Huston.

- `article-index.csv` lists the Hebrew title, publication date, original publisher URL, archive files, and existing GitHub source where available.
- `image-to-article.csv` links 93 Cloudinary assets and checklist entries to articles or records why a match remains unresolved. The earlier position column uses the numbering in the image-placement report. The asset ID is the durable Cloudinary reference.
- `articles/` contains readable Hebrew Markdown, clean Hebrew HTML, and provenance for each text capture. It also contains verified print PDFs and web printouts where available. The Huston feature is provided as the original PDF.

Captions and credits in the crosswalk apply to the identified publisher image or checklist reference. A photo linked by subject has no verified publisher caption. For Edie Falco, the portfolio portrait points to the 2006 interview. The separate 2009 review is listed as related coverage.

The Markdown and HTML preserve source image links. For a local offline copy of the original layout, open the PDF where one is included.
